O código do produto não foi alterado. Cada PNG contém o prompt de geração nos metadados, e cada imagem tem um `.json` ao lado com prompt e notas do mockup. As rotas `/visual-smoke` são páginas técnicas de demonstração para desenvolvimento; não representam áreas de produto.
